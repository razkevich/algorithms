Strongly Connected Components

An SCC is a set of nodes where every node can reach every other node. An edge within an SCC is part of a mutual cycle; an edge between SCCs is one-way (if it were two-way, the two SCCs would merge into one).

SCC A: {1, 2, 3}    SCC B: {4, 5}    SCC C: {6}

Solid grey arrows = edges within an SCC. Dashed red arrows = cross-SCC "bridges" (one-way, form the condensation DAG).

Condensation — collapse each SCC to one node

Treat each SCC as a single super-node. What remains is always a DAG (no cycles between SCCs — if there were, they'd be one bigger SCC).

Reading the condensation: SCC A is a source (no incoming), SCC C is a sink (no outgoing). Kosaraju's trick: the highest-finish-time node lives in a source SCC of the original; after transposing the graph, that source SCC becomes a sink — so DFS from it is trapped in one SCC. Peel, repeat.
