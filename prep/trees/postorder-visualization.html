Iterative Post-Order: Record After Children Are Done

Post-order processes children before the parent.
The trick: peek at the top of the stack — only pop when both children are finished.

// Peek, don't pop. Only pop when children are done.
while (cur != null || !stack.isEmpty())
  while (cur != null)   // drill left
    stack.push(cur); cur = cur.left;
  peek = stack.peek();
  if (peek.right != null && peek.right != lastVisited)
    cur = peek.right;  // go right first
  else
    pop, record, lastVisited = peek;
